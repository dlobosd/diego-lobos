# Diego Lobos — Currículum y portafolio

Sitio personal de Diego Tomás Lobos Díaz, estudiante de Ingeniería Civil Informática en la Universidad Andrés Bello.

Web: https://dlobosd.github.io/diego-lobos/

Este repositorio es una copia personal de [Folio](https://github.com/dlobosd/folio). La plantilla genérica y su demo permanecen separadas: https://dlobosd.github.io/folio/.

## Actualizar mis datos

Edita `src/data/perfil.js`. Los cambios en `main` se compilan y publican automáticamente con GitHub Actions.

## Desarrollo

Requiere Node.js 22.12+ compatible con Astro.

```sh
npm ci
npm run dev
npm run build
```

El CV web se adaptó del documento facilitado por Diego. No incluye correo ni teléfono sin completar. El nivel C1 se indica como autoevaluado y la certificación EF SET como pendiente de confirmar.
